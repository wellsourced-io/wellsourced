## How to use

Tokens are declared on <code>:root</code> in <code>src/app/globals.css</code> and exposed to Tailwind v4 via <code>@theme inline</code>. Inside the app, prefer Tailwind utilities that reference the tokens (<code>bg-teal</code>, <code>text-fg</code>, <code>rounded-[16px]</code>, etc.). When Tailwind doesn't cover a case, use the raw variable: <code>var(--color-teal)</code>.

## Dark mode

Dark mode re-points the semantic tokens. Core palette values stay where they are; the app's surfaces and text swap.

<CodeBlock language="css" filename="globals.css">{`html[data-theme="dark"] {
  --color-bg: #0c0c18;
  --color-surface: #151527;
  --color-fg: #f5f0e8;
  --color-muted: #8a94a6;

## Tailwind mapping

Tokens are exposed via <code>@theme inline</code> — class names like <code>bg-teal</code>, <code>text-fg</code>, <code>border-border</code>, <code>text-muted</code>, <code>bg-surface</code>, <code>bg-sand</code> all work out of the box.
