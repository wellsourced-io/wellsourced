## Rules

- **Use Lucide.** Do not mix icon sets. If Lucide doesn't have what you need, ask in content before drawing a custom one.
- **Default size 24&thinsp;px at 1.5&thinsp;px stroke.** Smaller UIs scale down to 16&thinsp;px but keep the stroke.
- **Currents, not colors.** Icons inherit `currentColor`. Apply color on the wrapping element, not on the icon directly, so they track theme.
- **Icon alone is not an action.** Every interactive icon gets an accessible label (`aria-label` or an adjacent text label).
- **Trust tier icons are fixed.** T1 = UserCheck, T2 = Users, T3 = ShieldCheck. Do not swap.
