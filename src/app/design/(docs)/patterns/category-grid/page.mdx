## Rules

- **Four columns on desktop, two on mobile.** Eight categories max per page — if you have more, curate.
- **Count is mono, muted.** It's metadata, not a pitch. “284” reads as scale without shouting.
- **Hover lifts, doesn't color-flood.** Border turns teal, card nudges 1&thinsp;px. No fills, no big shadows.
- **Icons describe, not decorate.** If a user has to squint to know what the tile is about, the icon is wrong.
