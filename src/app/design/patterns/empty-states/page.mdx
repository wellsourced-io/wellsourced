## Rules

- **Never apologize.** “Sorry, no results found” is a cop-out. Tell the user what to try instead.
- **Offer a next action.** Every empty state has at least one button. “Clear filters”, “Try a related term”, “Submit a brand”.
- **Don't fake emptiness.** If there are zero products because the index is down, say that — don't show “no matches found”.
- **Keep copy short and specific.** The heading names what's missing; the paragraph gives one reason and one way out.
