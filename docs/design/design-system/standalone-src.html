08

Motion

Motion is structural, never decorative. We move things to confirm an action, surface a state, or hand off focus — nothing swoops, nothing bounces. A shopper should never wait on an animation to complete.

8.1 Principles

four rules, in order of priority
01 · HONEST
Motion reflects real state.
A spinner means we're actually fetching. A pulse means data is live. We never animate to imply speed we don't have.
02 · FAST
Under 250ms, almost always.
Shoppers click. Long animations feel like lag. If it can't be 250ms, it probably shouldn't animate.
03 · QUIET
No bounce, no overshoot.
We use cubic-bezier(.2,.7,.3,1) for everything. No spring, no elastic — this is research infrastructure, not a game.
04 · RESPECTFUL
Respects reduced-motion.
Every transition is gated by prefers-reduced-motion. No exceptions.

8.2 Duration scale

five timings — use these, don't invent new ones
80ms
instant
Tap feedback, focus ring, checkbox tick. Below perceptual threshold — feels immediate.
150ms
micro
Button hover, chip toggle, arrow nudge, color fade. Default for all interactive states.
200ms
small
Card lift, tooltip fade, filter chip dismiss. Things that change position a few pixels.
240ms
medium
Modal open, drawer slide, tooltip popover. Things that reveal new content.
320ms
page
Full-screen transitions only — route change, mobile search overlay. Used sparingly.
// anything above 320ms is reserved for skeleton loaders and data-streaming states

8.3 Easing

one curve, two edge cases
Standard — default for everything
cubic-bezier(.2, .7, .3, 1)
Confident entrance, quiet settle. Use for hover, fade, lift, slide — 99% of motion.
Symmetrical
cubic-bezier(.4, 0, .2, 1)
Content shifts that need to feel neutral — accordion open, skeleton pulse. No directional bias.
Exit
cubic-bezier(.4, 0, 1, 1)
For things leaving the screen — modal close, toast dismiss. Faster start, no lingering.
// NEVER use spring, elastic, or back-out. Bouncy motion reads as toy-like. We are a commons.

8.5 Don't

anti-patterns
✕
Parallax on scroll
Implies marketing. We're a product search engine, not a landing page.
✕
Number count-ups
“1,247 brands” appearing slowly reads as fake. Just show the number.
✕
Bouncy springs
Undermines the institutional tone. Leave overshoot to consumer apps.
✕
Decorative loops
Animated backgrounds, floating shapes, gradient pulses — all out. Motion means something happened.
09

Imagery

Imagery must earn its place. Product shots do the job, brand photography provides context, and everything else — stock illustrations of handshakes, planet icons, smiling families — is out. If an image doesn't tell the user something they can't read, delete it.

9.1 Principles

four rules — every image is evaluated against these
01 · USEFUL
Shows the product.
The shopper is scanning. Product-on-background wins every time over lifestyle context.
02 · SOURCED
From the brand itself.
Fetched from the brand's Shopify. Never stock photos, never AI-generated. Real or nothing.
03 · CREDITED
Attribution visible.
Every non-product photo names the photographer or source. No anonymous imagery on a transparency platform.
04 · HUMAN, NOT HAPPY
Documentary, not marketing.
When we show makers or facilities, show work. Hands, workshops, process. No cheerful founder portraits.

9.2 Image categories

five types — each has its own treatment
PRODUCT SHOT · 1:1 · 1200px
01 · Product
Used in: search cards, brand profile galleries, category browse.
  • ✓ Square crop, product centered, 15% padding min
  • ✓ Plain background or consistent brand treatment
  • ✕ No overlay text, no “SALE” stickers, no lifestyle clutter
MAKER PORTRAIT · 4:5 · documentary
02 · Maker & workshop
Used in: brand profile header, ownership sections, contributor evidence.
  • ✓ Working portraits — hands, tools, process
  • ✓ Natural light, minimal color grading
  • ✕ No staged smiles, no corporate headshots
DOCUMENT SCAN · 16:10 · cropped
03 · Document & evidence
Used in: trust tier sources, audit trail, verification receipts.
  • ✓ Real scans — B Corp certificates, SEC filings, cooperative bylaws
  • ✓ 8px corners, subtle shadow, always with source URL
  • ✕ No mocked-up documents, no stock “paperwork” photos
PLACE · 16:9 · workshop / origin
04 · Place of origin
Used in: HQ location cards, manufacturing context, transparency sections.
  • ✓ Wide establishing shots — the actual factory, farm, or studio
  • ✓ Include geographic context (map pin, region label)
  • ✕ No generic city skylines, no stock “factory” photos
BRAND LOGOMARK · 1:1 · SVG preferred
05 · Brand logomark
Used in: product cards, brand profile headers, search autocomplete.
  • ✓ SVG where possible, PNG with transparent background as fallback
  • ✓ Sits on white — never on warm sand, never on teal
  • ✕ No cropping wordmarks, no recoloring brand assets

9.4 Do & Don't

the calibration check
DO
Product-on-white · edges breathing
Clean, centered, product speaks for itself. Shopper's eye lands on the object.
DON'T
35% OFF
Sale stickers · lifestyle clutter
Overlays imply a marketplace. We link out — pricing lives on the brand's store.
DO
Hands at work · natural light
Process over person. What they make is more interesting than how they smile.
DON'T
Stock founder portrait · crossed arms
Pose photography reads as PR. We are not the brand's agency.
DO
Scanned B Corp certificate · with URL
Real evidence. Source visible. Contributor name attached.
DON'T
🌿
Generic leaves, handshakes, globes
Sustainability clip art is the greenwashing tell. The data earns trust — not the icon.

9.5 Missing imagery

placeholder — not a default image
No product image yet
No maker photo yet
When an image is missing, say so.
A warm-sand tile with a monospace label is better than a broken image, a stock fallback, or an AI-generated guess. It's also an honest invitation — contributors can see what's missing and submit it.
// if it can't be real, it can wait. placeholders are a feature, not a failure.
